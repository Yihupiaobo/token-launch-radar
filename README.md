A token launch radar that prices every pre-token protocol in the sealed DefiLlama snapshot by the market-cap/TVL multiples of its live-token peers in the same category, adjusted for 7-day growth, time live with no token, and multi-chain breadth — then ranks all 213 of them, each with a seven-step farm plan with costs and times, in a filterable dashboard with a detail view per protocol and a confidence grade per estimate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
